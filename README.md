# Welcome to Bog Roll

## NOW AVAILABLE ON STEAM - https://store.steampowered.com/app/2406060/Bog_Roll

### Contact robfraserdesign@gmail.com for a FREE key to review the game!

The year's 2020 and during the peak of Australia's lockdown there's a toilet roll (or bog roll) shortage. You play as
Jim, who, of course, always leaves things to the last minute and forgot to stock up on bog rolls. Collect as many bog
rolls as you can while discovering the many secrets on this whirlwind adventure!

## KEY FEATURES

- 2D platformer with classic pixel art
- 7 unique levels + 1 bonus level
- Aussie humor
- Secrets galore
- Hidden shungites

## Key Features

- **Classic 2D Platformer**: Smooth controls and challenging jumps in a retro pixel art style.
- **Multiple Levels**: 7 unique main levels plus 1 bonus level filled with variety and surprises.
- **Aussie Humor**: Packed with local references, puns, and relatable lockdown-era jokes.
- **Secrets and Collectibles**: Hidden areas, easter eggs, and collectible shungites to discover.
- **Pixel Art and Sound**: Hand-crafted visuals and immersive audio by the solo developer.

## Development

- **Engine**: Built with Unity
- **Creator**: All art, programming, design, and music by Rob Fraser
- **Public Repo**: This repository serves as the public-facing source for the game project.
- **Languages**: Primarily C# with some ShaderLab and HLSL

## How to Play / Install

The game is available for purchase or review keys on Steam. For developers interested in the source:
1. Clone the repo: `git clone https://github.com/robFraser1111/BogRoll-Public.git`
2. Open the project in Unity Hub (ensure compatible Unity version)
3. Build for your platform and run

**Note**: This public repo may not include all private assets or full development history. It's for reference and community.
